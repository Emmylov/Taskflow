---
name: TaskFlow agency-template demos
description: Product requirements for public sample role previews and real account authorization.
---

TaskFlow is intended to be sold as an agency template. Prospective buyers need to preview client, creator, and admin experiences.

**Why:** The user explicitly wants buyers to demo every account type, especially admin, without compromising real accounts.

**How to apply:** Keep sample previews clearly labeled and isolated from authenticated data and APIs. Never let a client-side role switch grant permissions in the real app.
